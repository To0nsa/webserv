Detailed Description

Simple color-coded logging utility.

Implements the Logger class methods and related helper functions for mapping log levels to human-readable strings and ANSI terminal colors. Supports standard log levels (DEBUG, INFO, WARN, ERROR) and can optionally prefix messages with a source identifier.

Output is written to stdout for non-error messages and stderr for ERROR level messages, ensuring separation of normal and error output streams. ANSI escape codes are used for color, which may not render correctly in all terminals.

Note
This logger is intended for human-readable output during development and runtime diagnostics, not structured logging. For production environments or log parsing, consider extending it to support formats like JSON or syslog.
