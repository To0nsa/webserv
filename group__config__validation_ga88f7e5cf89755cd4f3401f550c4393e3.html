void anonymous_namespace{validateConfig.cpp}::validateErrorPageCodes ( const std::vector< Server > &  servers)

Validates that all configured error_page directives use valid HTTP status codes.

Iterates over each server’s error_page mappings and ensures that every status code falls within the HTTP error range 400–599. These codes represent client (4xx) and server (5xx) errors only. Other codes (e.g., 200, 301) are not valid for error pages.

Parameters
serversVector of configured Server objects to validate.
Exceptions
ValidationErrorif:
  • Any error_page status code is outside the 400–599 range.
