HttpResponse ResponseBuilder::generateError ( int  status_code,
const Server &  server,
const HttpRequest &  request 
)

Builds an HTTP error response, optionally using a custom error page.

This helper constructs error responses in two stages:

  1. It checks the server configuration for a custom error page matching the given status code (via Server::getErrorPages). If found, it attempts to read the file and use its contents as the response body.
  2. If no custom page is configured or the file cannot be read, it falls back to generating a minimal default HTML page with the status code and reason phrase (e.g., "404 Not Found").

In both cases, the response is initialized with correct status line, HTTP version, and connection persistence rules using initializeResponse, and the Content-Type is set to "text/html".

This ensures clients always receive a valid, informative error page, even if the custom configuration fails.

Parameters
status_codeThe HTTP error code to return (e.g., 404, 500).
serverReference to the Server configuration, used to look up custom error pages.
requestThe original HttpRequest, used for version and connection metadata propagation.
Returns
A fully constructed HttpResponse object representing the error.
