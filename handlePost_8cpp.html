Detailed Description

Implements HTTP POST request handling logic.

This file provides the full workflow for processing POST requests:

  • Validating request body size and upload configuration.
  • Normalizing and securing the target upload path against symlinks, escapes, and unsafe locations.
  • Supporting multiple content types:
    • multipart/form-data → handled by handleMultipartForm.
    • application/x-www-form-urlencoded → parsed into key/value pairs and saved as HTML.
    • Raw body data → stored directly as a file.
  • Generating safe, unique filenames for uploads when needed.
  • Returning appropriate HttpResponse objects:
    • 201 Created with confirmation on success.
    • Error responses (400, 403, 404, 413, 500) on invalid or failed operations.
