int runWebserv ( int  argc,

Runs the Webserv server.

Bootstraps the application by resolving the config path, loading and parsing the configuration, normalizing defaults, validating constraints, and launching the non-blocking socket manager event loop.

Parameters
argcArgument count.
argvArgument vector. Optional: path to the configuration file.
Returns
EXIT_SUCCESS on clean shutdown; EXIT_FAILURE is returned by main() on errors.
Exceptions
std::runtime_errorIf CLI arguments are invalid or the config file cannot be opened.
ConfigParseErrorIf the configuration cannot be tokenized/parsed.
ValidationErrorIf the resulting configuration fails validation rules.
