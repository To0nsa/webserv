void SocketManager::initializeClientInfo ( int  client_fd,
int  listen_fd 
)
private

Initializes tracking information for a newly accepted client.

Creates or resets a ClientInfo entry for the given client file descriptor:

  • Stores the client FD for later reference.
  • Initializes timestamps (lastRequestTime, connectionStartTime).
  • Resets request/response state (header/body counters, completion flags).
  • Clears send progress tracking (bytes_sent).
  • Associates the client with all servers (virtual hosts) listening on the same port as the accept()'ed socket.
Parameters
client_fdFile descriptor of the newly accepted client socket.
listen_fdFile descriptor of the listening socket that accepted this client.
