bool SocketManager::isBodyTimeout ( int  fd,
time_t  now 
)

Detects request body timeout for a client connection.

This timeout applies when:

  • No response is currently being sent (responses and current_raw_response empty),
  • The HTTP headers have already been received completely (headerComplete == true),
  • And the elapsed time since connectionStartTime exceeds TIMEOUT.

This typically indicates that the client started a request but did not finish sending the body in time (e.g. stalled upload or slowloris-style attack).

On timeout, a 408 Request Timeout is queued via respondError and the function returns true, so the caller may disable reads (POLLIN) and flush the error.

Parameters
fdClient socket file descriptor.
nowCurrent server time snapshot.
Returns
true if a body timeout occurred and an error response was queued, otherwise false.
Note
The connection is not closed immediately; it is marked for sending the 408 response before shutdown.
