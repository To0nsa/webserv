Generates an HTTP redirect response.

Creates a response with the given redirect status code (e.g., 301 Moved Permanently, 302 Found, 307 Temporary Redirect), sets the appropriate Location header pointing to the target URL, and applies connection-handling logic via initializeResponse.

By default, no response body is included for redirects, and most clients rely solely on the Location header. A Content-Length: 0 header may be explicitly added if desired, but is optional.

Parameters
status_codeRedirect status code (must be in the 3xx range).
locationTarget URL or path for the redirect.
requestThe original HTTP request (provides metadata for connection handling).
Returns
An initialized HttpResponse representing the redirect.
