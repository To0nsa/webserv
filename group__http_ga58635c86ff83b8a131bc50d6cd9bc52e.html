Parses and validates the HTTP request body according to Content-Length or Transfer-Encoding.

This function handles two body transfer mechanisms:

  • Chunked transfer encoding: waits until the terminating 0\r\n\r\n is received, then delegates parsing to chunkReqHandler. Rejects incomplete or malformed chunked bodies.
  • Fixed-length bodies: uses the Content-Length header to determine how many bytes to consume, rejecting requests that exceed clientMaxBodySize or contain mismatched lengths.

It also supports HTTP/1.1 pipelining:

  • If extra bytes follow a complete body, the function checks whether they look like the start of another request (via isLikelyStartLine).
  • If so, only the declared body is consumed and parsing can continue with the next request.
Parameters
reqThe HttpRequest object being filled.
bodyPartRaw body data extracted from the client buffer.
clientMaxBodySizeMaximum allowed body size (from server configuration).
errorCodeReference set to HTTP error code on failure (0 on success).
consumedBytesReference updated with the number of bytes consumed from bodyPart.
Returns
true if the body is complete and valid, false if more data is needed or if an error occurred.
