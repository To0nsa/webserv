bool SocketManager::checkRequestLimits ( int  fd)
private

Enforces request size limits for an active client connection.

This function checks whether the accumulated request headers for a client exceed the configured maximum length (HEADER_MAX_LENGTH).

Behavior:

  • If the header is incomplete and the number of bytes received so far exceeds the allowed maximum, the server immediately queues a 431 Request Header Fields Too Large error response using respondError(), and returns true.
  • Otherwise, the request is considered within limits and processing continues.
Parameters
fdThe socket file descriptor of the client being checked.
Returns
true if the request exceeded the configured header limit (error response queued), false if still within allowed limits.
Note
This check is only enforced before header completion. Once headers are fully parsed, the limit is no longer evaluated here.
