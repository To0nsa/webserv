HttpResponse handleRequest ( const HttpRequest &  request,
const Server &  server 
)

Top-level router entrypoint for processing an HTTP request.

Forward declaration of the HttpResponse class.

This function implements the main request handling pipeline:

  1. Normalize URI — sanitize the request path.
  2. Directory-slash redirect — if a directory is requested without a trailing slash, generate a 301 redirect (see redirectOnDirectorySlash).
  3. Location resolution — find the best-matching Location in the server configuration (exact or longest-prefix match).
  4. Configured redirect — apply return directive–based redirects if present in the matched location (see redirectOnConfigured).
  5. Method validation — reject unsupported (501) or disallowed (405) methods (see validateRequestMethod).
  6. Dispatch — call the concrete handler for GET/POST/DELETE (see dispatchByMethod).

Errors at any stage are logged and turned into responses via ResponseBuilder.
