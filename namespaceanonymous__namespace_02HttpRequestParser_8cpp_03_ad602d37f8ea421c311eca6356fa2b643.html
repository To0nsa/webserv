Parses a full URL string into its components (HTTP/1.1 version).

This function is specialized for HTTP/1.1 requests:

  • Verifies that the mandatory Host header is present when the request version is HTTP/1.1 (RFC 7230 §5.4).
  • Uses a regular expression to parse the URL into its components:
    • Scheme (e.g., http, https)
    • User (optional username)
    • Password (optional password)
    • Host (domain or IP address)
    • Port (optional numeric port)
    • Path (resource path, e.g., /index.html)
    • Query (optional ?param=value part)
    • Fragment (optional #section part)
  • Throws std::invalid_argument if the URL is invalid.
Parameters
reqThe associated HttpRequest, used to validate presence of the Host header when using HTTP/1.1.
urlThe raw URL string extracted from the request line.
Returns
A populated Url structure containing parsed fields.
Exceptions
std::invalid_argumentIf the Host header is missing (HTTP/1.1) or the URL does not conform to the expected syntax.
