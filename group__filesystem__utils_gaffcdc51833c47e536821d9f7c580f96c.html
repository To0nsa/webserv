◆ resolvePhysicalPath()

std::string resolvePhysicalPath ( const HttpRequest &  req,
const Location &  loc 
)

Resolves a request URI to a concrete filesystem path.

Computes the physical path for a request by: 1) Normalizing the request path and attempting resolution under the location's root. 2) If the resource is not a POST target and exists, returns that path. 3) Otherwise, when uploads are enabled and the URI is within the location prefix, rewrites the path into the configured upload store (joining with the remaining relative suffix). 4) Falls back to the root-based path even if it does not exist, allowing later handlers to emit the appropriate HTTP status (e.g., 404).

Parameters
reqIncoming HTTP request (method and normalized URI are consulted).
locMatched location block providing root, path prefix, and upload settings.
Returns
Fully-resolved absolute filesystem path. Returns an empty string when the normalized request path is empty (invalid or unsupported path).
Exceptions
std::runtime_errorOnly if helper utilities (e.g., normalization/join) are documented to throw on invalid inputs (none are thrown in the current logic).
Note
For POST requests, existing files under the root are intentionally ignored to avoid accidental overwrite semantics; uploads are routed to the upload store when configured.
Warning
Callers should not assume the returned path exists unless they checked it. Existence checking is deliberately limited to the non‑POST, root‑based branch.
