◆ joinPath()

std::string joinPath ( const std::string &  base,
const std::string &  suffix 
)

Concatenates a base path and a suffix with a single '/' separator.

Ensures that there is exactly one directory separator between the base and suffix, regardless of whether the base already ends with a slash. Does not normalize or validate the components; callers should sanitize inputs beforehand (e.g., via normalizePath). Intended for filesystem path assembly when resolving HTTP request targets to physical files or upload locations.

Parameters
baseBase path (absolute or relative). May end with '/'.
suffixPath fragment to append (should not begin with '/' unless intentional).
Returns
Combined path string.
Note
If base is empty, the function returns suffix unchanged.
Warning
This function does not handle '.' or '..' resolution; use only with trusted, normalized inputs to avoid directory traversal.
