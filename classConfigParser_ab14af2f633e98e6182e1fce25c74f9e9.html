Location ConfigParser::parseLocation ( )
private

Parses a single location block inside a server block.

Ensures the block starts with the location keyword, validates and sets the location path, then iterates over its contained directives. Each directive is validated for duplicates (unless repeatable) and dispatched to the appropriate handler. The block must end with a closing brace }.

Returns
A fully constructed Location object populated with directives.
Exceptions
SyntaxErrorIf the block is malformed, the path is missing or invalid, contains duplicate directives, or is missing required braces.
