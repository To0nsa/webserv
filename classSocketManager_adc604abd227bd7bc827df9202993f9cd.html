Initializes and starts a CGI process for a client request.

  • Allocates a new CgiProcess in the client state.
  • Attempts to initialize the CGI environment via CGI::initCgiProcess.
    • On success: leaves the process active and returns true.
    • On failure:
      • Logs an error with details.
      • Queues an error HttpResponse (e.g. 500, or errorCode returned).
      • Cleans up CGI state and clears the current request.
      • Returns false.
Parameters
client_fdThe client file descriptor.
requestThe HTTP request to be executed by CGI.
serverThe server context for this request.
locationThe location context where CGI execution is configured.
Returns
true if CGI initialization succeeded, false if an error response was queued instead.
