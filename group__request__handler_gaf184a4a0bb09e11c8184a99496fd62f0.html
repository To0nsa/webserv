Dispatch POST handling based on the request's Content-Type.

Chooses the appropriate handler:

  • multipart/form-data → handleMultipartForm (saves parts into targetDirectory).
  • application/x-www-form-urlencoded → handleUrlEncodedForm (writes parsed HTML to targetPath).
  • **(fallback)** any other/absent type → handleRawBody (dumps raw body to targetPath). 
         This function relies on a simple substring match of the `Content-Type`
     header. If you later support parameters (e.g. `charset=...`) or more
     types, consider normalizing and parsing the media type token.
    Parameters
    requestIncoming HTTP request (provides headers/body).
    serverServer context (for error responses).
    targetPathAbsolute file path chosen for single-file saves.
    targetDirectoryDirectory path to store multipart parts.
    targetFilenameLeaf filename for single-file saves.
    Returns
    A populated HttpResponse produced by the selected handler.
