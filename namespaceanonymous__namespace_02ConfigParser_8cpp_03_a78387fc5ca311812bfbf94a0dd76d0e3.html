Dispatches a configuration directive to its registered handler.

Looks up the directive keyword (from the current token) in the provided handler table. If a matching handler is found, it is invoked with the target object (Server or Location), parsed values, source position (line/column), and contextual snippet. If no handler exists for the directive name, a SyntaxError is thrown.

Template Parameters
TThe type of the configuration target (e.g., Server or Location).
HandlerMapA mapping from directive name (std::string) to a handler function/lambda capable of applying the directive.
Parameters
targetThe configuration object being populated (Server/Location).
tokenThe token representing the directive keyword.
valuesList of string arguments parsed for the directive.
handlersMap of directive names to handler functions.
lineLine number in the source config where the directive occurs.
columnColumn number in the source config where the directive occurs.
ctxA snippet of the source line for contextual error messages.
Exceptions
SyntaxErrorIf the directive name is unknown or unhandled.
