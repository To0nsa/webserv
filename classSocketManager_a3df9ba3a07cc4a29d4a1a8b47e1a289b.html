Sends an in-memory (raw) HTTP response to a client.

Handles responses that are already fully materialized in memory: 1) On first call, serialize the HttpResponse to a byte string (toHttpString()) and reset the per-client send offset. 2) Perform non-blocking send() of the remaining bytes; update bytes_sent. 3) When all bytes are sent:

  • Pop the response from the queue,
  • Clear the staging buffer and reset offset,
  • Honor connection policy:
    • Connection: close → close FD,
    • keep-alive → if no more responses, drop POLLOUT to avoid busy loops.

Error handling:

  • On send() failure, logs the error and closes the connection.
Parameters
fdClient socket file descriptor.
indexIndex of the client FD in the poll list.
responseThe response object to serialize and send.
Returns
true if the socket remains usable (may need more sends), false if the connection was closed or a fatal error occurred.
