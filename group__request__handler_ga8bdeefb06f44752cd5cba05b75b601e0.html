Renders a single <tr> row in the autoindex HTML table.

Converts a directory entry into a clickable HTML link with metadata (last modified, size).

  • The ".." entry is treated as a parent directory link.
  • Directories get a trailing slash (/) in both display and href.
  • Files show their size in bytes, while directories/".." show "-".
  • Icons: 📁 for directories, 📄 for files.
Parameters
bodyOutput stringstream accumulating the HTML response.
entryDirectory entry metadata (name, size, mtime, type).
baseUriBase URI (must end with /) to prepend to href links.
Note
This function applies both escapeUriComponent (for href safety) and htmlEscape (for display safety), preventing XSS or broken links.
