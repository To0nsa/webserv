Detailed Description

Declares the HttpResponse class.

Represents an outgoing HTTP response, including status line, headers, body payload, and optional file-backed or CGI-generated content. Provides setters for constructing responses and utilities such as toHttpString() for serialization to the raw wire format.

This class is produced by response builders (see ResponseBuilder), handlers (GET/POST/DELETE/CGI), and consumed by the networking layer when writing responses back to clients.
