std::optional< HttpResponse > anonymous_namespace{requestRouter.cpp}::validateRequestMethod ( const HttpRequest &  request,
const Location &  loc,
const Server &  server 
)

Validates the HTTP method against server support and location policy.

Two checks in order: 1) Server support: rejects methods not implemented by this server (currently {"GET","POST","DELETE"}) with 501 Not Implemented. 2) Location policy: rejects methods not allowed by the matched Location with 405 Method Not Allowed.

Both cases are logged and rendered via ResponseBuilder::generateError.

Parameters
requestIncoming HTTP request (used for method/path and response metadata).
locMatched configuration block to query method allowance.
serverActive server (used by error rendering).
Returns
std::nullopt when the method is valid for this location; otherwise a ready error HttpResponse (501 or 405).
Note
Per RFC 9110, servers SHOULD include an Allow header on 405 listing permitted methods for the target resource.
Warning
Method matching here is case-sensitive; normalize upstream if you want to accept non‑uppercase tokens.
