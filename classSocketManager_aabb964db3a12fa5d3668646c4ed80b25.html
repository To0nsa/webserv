Processes incoming data for a client connection.

Called when a client socket is readable (POLLIN):

  1. Reads available data from the client using receiveFromClient.
    • If the client disconnects or a read error occurs → return false (FD will be closed).
  2. Attempts to parse one or more complete HTTP requests from the buffer via parseAndQueueRequests.
    • If parsing is incomplete, waits for more data.
    • If a parse error occurs, queues an error response.
  3. Processes all queued requests (except those blocked by CGI execution) via processPendingRequests.

Exception safety:

  • Catches std::bad_alloc (memory exhaustion), std::exception, and unknown errors.
  • On error: disables further POLLIN events for this client and queues a 500 Internal Server Error.
Parameters
client_fdFile descriptor of the client socket.
indexIndex of the client FD in the internal poll list.
Returns
true if processing completed (even with errors queued), false if the connection should be closed.
