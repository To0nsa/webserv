std::size_t Server::getClientMaxBodySize ( ) const
noexcept

Returns the maximum allowed size for the request body.

This limit applies to the content length of incoming HTTP requests, including POST uploads. If exceeded, the server should return a 413 Payload Too Large error. Configured via the client_max_body_size directive.
