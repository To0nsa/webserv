Serves a static file in response to an HTTP GET request.

This helper reads a file from disk and builds the appropriate HttpResponse:

  • Verifies that the target is a valid file.
  • Opens the file in binary mode, rejects if inaccessible.
  • Determines the Content-Type header (uses detectMimeType if none is provided).
  • If the file size is small (≤ 100 KiB), reads the entire file into memory and returns it inline.
  • If the file size is larger, streams it back using ResponseBuilder::generateSuccessFile.

Logs each decision (missing file, forbidden, in-memory, or streaming).

Parameters
file_pathFilesystem path to the target file.
requestIncoming HTTP request.
serverActive server context (for error generation).
content_typeOptional MIME type override; if empty, auto-detected.
Returns
A valid HttpResponse:
  • 200 with body or stream on success.
  • 404 if file not found.
  • 403 if access is denied.
