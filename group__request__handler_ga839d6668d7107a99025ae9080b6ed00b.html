static

Detects the MIME type of a file based on its extension.

Uses a static lookup table mapping common file extensions (e.g., .html, .png, .json) to their corresponding MIME types. The file extension is normalized to lowercase before lookup. If the extension is not recognized, the generic application/octet-stream type is returned.

Parameters
file_pathPath to the file whose MIME type should be determined.
Returns
A MIME type string suitable for the Content-Type header.
