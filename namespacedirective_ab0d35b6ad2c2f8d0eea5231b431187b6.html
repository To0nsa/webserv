Validates the syntax of a CGI file extension.

This function ensures that a given CGI extension string is valid. A valid extension must:

  • Be non-empty.
  • Begin with a dot (.).
  • Contain only alphanumeric characters after the dot.
  • Not be just "." with no following characters.
Parameters
extThe extension string to validate (e.g., ".php").
lineLine number in the config file for error reporting.
columnColumn number in the config file for error reporting.
context_providerLazy-evaluated function returning a source context snippet.
Exceptions
SyntaxErrorIf the extension is malformed or contains invalid characters.
