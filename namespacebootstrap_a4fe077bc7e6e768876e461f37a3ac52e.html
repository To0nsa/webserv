std::string bootstrap::resolveConfigPath ( int  argc,
char **  argv 
)

Resolves the configuration file path from CLI arguments.

Accepts either zero or one user-supplied path. When no path is provided, the function returns the default path specified by DEFAULT_CONFIG_PATH. Passing more than one non-program argument is considered an error.

Parameters

argvArgument vector.
Returns
The resolved configuration file path.
