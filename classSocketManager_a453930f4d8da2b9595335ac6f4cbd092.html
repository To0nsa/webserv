bool SocketManager::isSendTimeout ( int  fd,
time_t  now

Detects send timeout for a client connection.

This timeout applies when:

  • There are still responses waiting to be sent (!responses.empty()),
  • A response is actively being transmitted (!current_raw_response.empty()),
  • But no progress has been made for more than TIMEOUT seconds (based on lastSendAttemptTime).

This usually indicates that the client has stopped reading from its socket (e.g., slow or dead client), preventing the server from completing the response.

On timeout, no error response is queued (since we are already mid-send), but the function signals the caller (true) so that the connection can be closed and cleaned up.

Parameters
fdClient socket file descriptor.
nowCurrent server time snapshot.
Returns
true if a send timeout occurred and the connection should be closed, otherwise false.
Note
Unlike header/body timeouts, this does not queue a 408 response, because the server was already in the process of sending a response.
