Detailed Description

Factory helpers for constructing HTTP responses.

The ResponseBuilder namespace groups together utility functions that generate fully-formed HttpResponse objects for different scenarios:

  • generateSuccess : Build a success response with an inline body.
  • generateSuccessFile : Build a response backed by a file (static file or CGI temp file).
  • generateError : Build an error response, using custom pages if available or a default fallback.
  • generateRedirect : Build a redirect response with a Location header.

All builders rely on initializeResponse to apply consistent status metadata, HTTP version, and connection persistence rules. This ensures uniform behavior across all response types.

These functions are typically used by request handlers, CGI logic, and the router when constructing responses to be sent back to clients.
