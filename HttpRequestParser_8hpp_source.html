15 * @brief Declares the HttpRequestParser utility class.
16 *
17 * @details Provides a static interface for parsing raw HTTP request strings
18 * into structured @ref HttpRequest objects. The parser extracts and
19 * validates the request line, headers, and body while handling
20 * connection-specific details such as consumed byte counts.
21 *
22 * The main entry point is @ref HttpRequestParser::parse, which:

24 * - Selects the matching @ref Server configuration from the list
25 * of available virtual hosts on the same port.
26 * - Returns any parsing error code and the number of bytes consumed
27 * from the raw input buffer.
28 *

30 *
31 * @ingroup http
32 */
