13/**
14 * @file methodsHandler.hpp
15 * @brief Declares HTTP method handlers for GET, POST, and DELETE.
16 *
17 * @details This header defines the public entrypoints for handling
18 * HTTP request methods within Webserv. Each function maps
19 * an incoming @ref HttpRequest to an @ref HttpResponse,
20 * using the active @ref Server context and the matched
21 * @ref Location configuration.
22 *
23 * Supported methods:
24 * - **GET**: Serves static files or generates autoindex
25 * listings (see @ref generateAutoindex).
26 * - **POST**: Handles uploads (raw body, URL-encoded,
27 * multipart forms).
28 * - **DELETE**: Removes existing files if permitted.
29 *
30 * Helper:
31 * - @ref generateAutoindex: builds a directory listing
32 * response in HTML.
33 *
34 * @ingroup request_handler
35 */
