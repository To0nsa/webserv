Detects header read timeout for a client connection.

Triggers when:

  • No response is currently being sent (responses and current_raw_response empty),
  • The HTTP headers are not yet complete (headerComplete == false) but at least one header byte has arrived (headerBytesReceived > 0),
  • And the elapsed time since connectionStartTime exceeds HEADER_TIMEOUT_SECONDS.

On timeout, queues a 408 Request Timeout via respondError and returns true so the caller can disable further reads (POLLIN) and flush the error response.

Parameters
fdClient socket file descriptor.
nowCurrent time snapshot used for comparison.
Returns
true if a header timeout was detected and an error response was queued, otherwise false.
Note
This does not close the connection immediately; the caller is expected to keep the socket writable to send the queued 408 response.
