Handles an HTTP request error by generating and queuing an error response.

  • Builds an error HttpResponse using ResponseBuilder::generateError.
  • Pushes the response into the client’s response queue.
  • Removes the faulty request from the pending request queue.
  • Returns whether the response requires closing the connection (e.g. HTTP/1.0 without keep-alive).
Parameters
fdFile descriptor of the client connection.
codeHTTP status code to return (e.g. 400, 404, 413).
reqThe offending HTTP request (may be partially parsed).
serverThe server context used for error page resolution.
Returns
true if the error response requires closing the connection, false otherwise (keep-alive).
