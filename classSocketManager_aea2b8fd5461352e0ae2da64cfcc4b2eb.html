void SocketManager::handleCgiPollEvents ( )
private

Monitors and manages active CGI processes for all clients.

Iterates over all connected clients and checks if a CGI process is associated with them. For each active CGI:

  1. Timeout check:
    • If the process has been idle longer than CGI_TIMEOUT_SECONDS, it is killed and a 504 Gateway Timeout response is queued.
  2. Completion check:
    • If CGI::tryTerminateCgi indicates the process is done, finalize output with CGI::finalizeCgi, push response, cleanup process state, and re-enable POLLOUT to send data.
    • After cleanup, if more requests remain queued for the client, continue processing them with processPendingRequests.
  3. Exception safety:
    • If any error occurs during CGI handling, logs the error, queues a 500 Internal Server Error, and cleans up CGI state.

Integration:

  • This method is called once per poll loop iteration before handling socket-level events.
  • It ensures CGI subprocesses do not block the server’s main loop.
