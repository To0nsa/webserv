Parses a human-readable byte size string into a byte count.

Converts a size string (e.g., "10K", "5M", "2G", or raw bytes "512") into a std::size_t representing the number of bytes. The suffix, if present, is case-insensitive and supports:

  • K = kibibytes (× 1024)
  • M = mebibytes (× 1024²)
  • G = gibibytes (× 1024³) Throws a ConfigParseError if:
  • The value is empty.
  • Parsing fails or extra non-numeric characters remain.
  • The computed size exceeds the 4 GiB hard limit from the Webserv spec.
Parameters
valueString containing the size to parse (may include suffix).
fieldName of the configuration field being parsed.
lineLine number in the configuration source.
columnColumn number in the configuration source.
context_providerCallable returning a string snippet or context for diagnostics.
Returns
Parsed size in bytes.
Exceptions
ConfigParseErrorIf the string is empty, cannot be parsed as a size, contains leftover characters, or exceeds the maximum allowed size.
Note
Used primarily to parse configuration directives like client_max_body_size.
