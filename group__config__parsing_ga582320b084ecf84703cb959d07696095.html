std::vector< std::string > ConfigParser::collectArgs ( std::span< const TokenType >  validTypes)
private

Collects a list of argument values following a directive.

This function consumes tokens that belong to the directive's argument list. It accepts only tokens of specific types (STRING, NUMBER, IDENTIFIER), provided in the validTypes span. Arguments may be separated by commas. Example: root /var/www; methods GET, POST, DELETE;

  • Stops parsing when a token does not match a valid argument type.
  • Supports comma-separated lists of arguments.
  • Throws if a comma is not followed by a valid argument.
Parameters
validTypesA span of allowed token types for directive arguments.
Returns
A vector of string values representing the collected arguments.
Exceptions
SyntaxErrorIf a comma is not followed by a valid argument type.
