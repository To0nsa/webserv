static

Validates that a normalized request path is safe and well-formed.

This function enforces basic security and syntax rules for HTTP request targets:

  • Must start with a leading / (absolute path).
  • The root path / is always valid.
  • Rejects empty paths or those not beginning with /.
  • Rejects traversal attempts such as /.., /../foo, or paths ending in /...
  • Rejects sequences that attempt to escape the root directory.

Note: Double slashes ("//") were considered for rejection but are currently allowed (commented out).

Parameters
rawPathThe request path string (after decoding and normalization).
Returns
true if the path is valid and safe, false otherwise.
