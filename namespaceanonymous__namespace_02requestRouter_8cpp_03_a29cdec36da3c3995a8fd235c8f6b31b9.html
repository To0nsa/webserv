Redirects to a slash-terminated URI when the target is a real directory.

This helper enforces nginx-like behavior for directory URIs: if the request path maps to a directory but lacks a trailing slash, issue a 301 redirect to the slash-appended path.

Rules:

  • Only considers Location blocks whose configured path ends with '/'.
  • Matches the request URI by location prefix (sans trailing slash).
  • Resolves a physical filesystem path with resolvePhysicalPath and checks it with stat; symlink-to-dir is treated as a directory.
  • Applies to any HTTP method (GET/POST/DELETE), not only GET.
Parameters
reqParsed HTTP request (used for path, method, headers).
serverActive server context (provides location list).
uriNormalized request URI (usually normalizePath(req.getPath())).
Returns
std::nullopt if no redirect is needed; otherwise a ready 301 response with Location: <path>/.
Note
If req.getPath() already ends with '/', no redirect occurs.
Warning
Only locations defined with a trailing slash are inspected; locations configured without a trailing '/' are intentionally ignored here.
