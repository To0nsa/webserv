ConfigParser::ConfigParser ( std::string  source)

Constructs a ConfigParser instance from raw configuration text.

Initializes the internal tokenizer with the provided configuration source string. Immediately tokenizes the input and stores the resulting token sequence for parsing. This makes subsequent parsing methods (parseConfig, parseServer, etc.) operate directly on a prebuilt token stream rather than raw text.

sourceRaw configuration string to be parsed.
