void SocketManager::cleanupCgiForClient ( int  client_fd)
private

Cleans up and resets CGI state for a specific client.

If the client identified by client_fd has an active CGI process, this function terminates it via CGI::cleanupCgi, resets its state, and clears the currently running CGI request. If no CGI process is active, the function returns without action.

Parameters
client_fdThe file descriptor of the client whose CGI state should be cleaned up.
Note
This function does not close the client connection itself — it only resets CGI-related state. Connection cleanup is handled separately.
