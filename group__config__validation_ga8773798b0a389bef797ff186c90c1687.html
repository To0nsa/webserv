void anonymous_namespace{validateConfig.cpp}::validateClientMaxBodySize ( const std::vector< Server > &  servers)

Validates that client_max_body_size is set to a positive value.

This function checks each server’s configured maximum request body size (client_max_body_size) to ensure it is not set to zero. A value of 0 would effectively disable all request bodies, which is considered an invalid configuration.

The size is typically specified in bytes or with human-readable units like k, m, or g (e.g., 1m = 1 megabyte).
