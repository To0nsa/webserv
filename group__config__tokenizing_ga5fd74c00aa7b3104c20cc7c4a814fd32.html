Token Tokenizer::parseStringLiteral ( )
private

Parses a quoted string literal.

Supports both single and double quotes. Enforces a 64 KiB maximum payload and forbids embedded newlines.

Returns
STRING token containing the unescaped contents.
Exceptions
TokenizerErrorOn newline, overflow, or EOF before closing quote.
