Handle a multipart/form-data POST request and persist the uploaded file.

  • Extracts the boundary from the Content-Type header.
  • Parses the multipart body to find the first file part.
  • Enforces client_max_body_size to prevent DoS.
  • Generates a fallback filename if none was provided.
  • Writes the file content to disk under the given upload directory.
  • Returns an appropriate HttpResponse:
    • 400 if malformed,
    • 413 if too large,
    • 500 if I/O fails,
    • 201 with a confirmation HTML page on success.
Parameters
requestIncoming HTTP request containing the multipart body.
serverServer configuration (used for limits and error pages).
fullDirPathAbsolute path of the directory where uploads are stored.
Returns
HttpResponse representing the outcome (success or error).
