Determines whether the TCP connection should be kept alive based on HTTP version and the Connection header.

Implements protocol-specific keep-alive rules:

  • HTTP/1.1: persistent connections are the default. Only "Connection: close" disables keep-alive.
  • HTTP/1.0: connections close by default. Only "Connection: keep-alive" enables persistence.
  • Other/unknown versions: defaults to closing the connection for safety.
Parameters
versionThe HTTP version string from the request (e.g. "HTTP/1.1").
connThe value of the Connection header, lowercase-insensitive.
Returns
true if the connection may be kept alive, false if it should close.
