Builds a successful HTTP response with an inline body.

This helper constructs a standard success response:

  • Looks up the default reason phrase for the given status code (e.g., 200 → "OK").
  • Initializes the response with status line, HTTP version, and connection persistence rules via initializeResponse.
  • Sets the Content-Type header to the provided MIME type.
  • Attaches the supplied response body directly in memory.

Typical use cases include sending JSON, HTML, or plain-text responses for successful GET/POST requests.

Parameters
status_codeThe HTTP status code to return (e.g., 200, 201).
bodyThe response body payload as a string.
content_typeThe MIME type for the body (e.g., "text/html", "application/json").
requestThe original HttpRequest, used to propagate version and connection metadata.
Returns
A fully constructed HttpResponse object ready to send.
