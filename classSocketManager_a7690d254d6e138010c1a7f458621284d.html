Handles error or hangup events reported by poll().

Interprets the poll revents mask for a given client file descriptor and logs the corresponding error type:

  • POLLNVAL: Invalid poll event on this fd.
  • POLLERR: Generic socket error.
  • POLLHUP: Client disconnected.

After logging, the client connection is closed and cleaned up via cleanupClientConnectionClose.

Parameters
fdThe file descriptor that triggered the error event.
indexIndex of the fd in the internal poll list.
reventsThe bitmask of poll events received for the fd.
