Ensures that the current token matches a specific expected type.

This method validates that the parser is currently positioned at a token of type expected. If the token matches, it is consumed (the parser advances by one). If not, an UnexpectedToken error is thrown with details about what was expected versus what was found.

Parameters
expectedThe exact token type required at this position.
contextHuman-readable context for error reporting (unused here but provided for consistency).
Exceptions
UnexpectedTokenIf the current token does not match expected.
