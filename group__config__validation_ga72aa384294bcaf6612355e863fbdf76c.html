void anonymous_namespace{validateConfig.cpp}::validateUniqueServerNames ( const std::vector< Server > &  servers)

Ensures uniqueness of server_name directives within each server block.

This function validates that no single server block declares the same server_name more than once. While multiple distinct names are allowed (for virtual hosting and aliases), each must be unique within the same server definition.

Validation rules:

  • A server_name must not appear more than once in the same server block.
  • Duplicate names within the same block trigger a ValidationError.
  • Cross-server duplicates are allowed if they bind to different host:port combinations (checked separately in validateUniquePorts).
