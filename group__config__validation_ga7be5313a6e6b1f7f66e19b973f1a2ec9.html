void anonymous_namespace{validateConfig.cpp}::validateRootsExist ( const std::vector< Server > &  servers)

Validates that all root directives point to existing directories.

Iterates over all server locations and verifies that:

  • Locations without a return directive must have a root.
  • The specified root path must exist on the filesystem.
  • The path must be a directory (not a file or invalid path).

This ensures that each location serving files has a valid, accessible root directory, preventing runtime errors due to missing or invalid paths.

Parameters
serversVector of configured Server objects to validate.
Exceptions
ValidationErrorif:
  • A location missing a return directive has no root.
  • The specified root path does not exist.
  • The root path exists but is not a directory.
