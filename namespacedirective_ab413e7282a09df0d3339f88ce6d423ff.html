Ensures that a directive has exactly the expected number of arguments.

Used during configuration parsing to validate that a directive (e.g., listen, root, client_max_body_size) is provided with the correct number of arguments. If the count does not match the expectation, a SyntaxError is thrown with contextual information about the directive, line, column, and source snippet.

Parameters
argsThe list of argument strings parsed for the directive.
expectedThe exact number of arguments required.
directiveThe name of the directive being validated.
lineThe line number in the config file where the directive appears.
columnThe column number in the config file where the directive appears.
ctxA snippet of the surrounding source text for error reporting.
Exceptions
SyntaxErrorIf the directive does not have exactly expected arguments.
