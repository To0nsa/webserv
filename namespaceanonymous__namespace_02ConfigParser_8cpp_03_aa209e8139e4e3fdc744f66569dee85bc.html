Checks whether a directive name is allowed (not duplicated).

Tracks encountered directive names within a block (server or location). If the directive is marked as repeatable, it is always accepted. Otherwise, the name is inserted into the seen set:

  • If insertion succeeds, the directive is new and valid.
  • If insertion fails, the directive is a duplicate and rejected.
Parameters
nameThe directive keyword being checked.
seenSet of already encountered directive names in the current block.
repeatableSet of directive names allowed to appear multiple times.
Returns
true if the directive is valid (new or repeatable), false if it is a duplicate and not allowed.
