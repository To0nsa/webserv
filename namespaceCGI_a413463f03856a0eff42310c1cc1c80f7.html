HttpResponse CGI::finalizeCgi ( CgiProcess &  cgi,
const Server &  server,
const HttpRequest &  req 
)

Finalize a CGI process by parsing its output and building an HTTP response.

  • Opens the CGI output file produced by the child process.
  • Scans up to the first 9KB (MAX_HEADER_SCAN) to locate the HTTP header delimiter.
    • If not found, logs an error and returns a 500 response.
  • Extracts and parses CGI headers:
    • Status: → HTTP status code (default = 200).
    • Content-Type: → MIME type (optional).
  • Computes the offset where the body starts and its size.
  • Builds an HttpResponse via ResponseBuilder::generateSuccessFile, which streams the body directly from the output file.
  • Marks the response with the CGI temp file path so it can be cleaned up later.
Parameters
cgiReference to the CgiProcess containing CGI state (output path, timestamps).
serverServer configuration (used for error responses).
reqOriginal HTTP request (used for logging and response metadata).
Returns
An HttpResponse containing either:
  • The CGI result (with headers + body).
  • Or an error response (500) if parsing/reading failed.
Note
Only the first 9KB of output is scanned for headers. Larger headers are unsupported.
Warning
Caller is responsible for eventually cleaning up the CGI temp file.
