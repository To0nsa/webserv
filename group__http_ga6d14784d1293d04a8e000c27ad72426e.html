Parses and validates the request line and headers of an HTTP request.

This function processes the "head" section of an HTTP request, which includes the request line (method, target, version) and all header fields. It performs:

  • Validation of the request line: • Ensures it contains exactly 3 fields (method, target, version). • Validates that the method token is syntactically valid. • Rejects empty fields.
  • Decoding and validation of the request-target: • Percent-decoding. • Rejects control characters. • Forbids absolute-URIs and fragments (#...). • Splits query parameters from the path. • Enforces maximum URI length. • Normalizes the path and blocks traversal attempts (..).
  • Header parsing: • Reads each header line, ensures proper format (key: value). • Delegates validation/merging logic to insertValidatedHeader.
  • URL building: • Uses the Host header and matched Server configuration. • Sets normalized host and stores full Url in the request.

On error, this function sets errorCode to the appropriate HTTP status code (e.g., 400, 403, 414, 505) and returns false.

Parameters
reqReference to the HttpRequest being populated.
headerPartRaw string containing the request line + headers.
errorCodeOutput parameter: set if parsing fails.
serversList of servers listening on the same port (for Host/ServerName matching).
clientMaxBodySizeOutput parameter: max body size derived from the selected server configuration.
Returns
true if parsing succeeds and req is populated, false otherwise (with errorCode set).
