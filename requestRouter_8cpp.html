Detailed Description

Routes parsed HTTP requests to the appropriate handler.

Implements the routing pipeline that maps an incoming HttpRequest to a HttpResponse using the active Server configuration and its Location blocks.

Workflow: 1) Directory slash redirect: If a request targets a physical directory without a trailing slash, issue a 301 to the slash-terminated URI (see redirectOnDirectorySlash). 2) Location resolution: Find the best matching Location by exact match or longest-prefix (see findLocation). 3) Configured redirects: Apply return-based redirects if present in the matched location (see redirectOnConfigured). 4) Method validation: Check supported/allowed methods, returning 501 or 405 as appropriate (see validateRequestMethod). 5) Dispatch: Call the concrete method handler (GET/POST/DELETE) (see dispatchByMethod).

Errors are rendered via ResponseBuilder helpers. Utilities from filesystemUtils are used to normalize URIs and resolve physical paths.
