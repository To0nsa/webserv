Ensures the current token matches one of several expected types.

This method is used when a directive or grammar rule allows multiple token types in the same position (e.g., STRING or IDENTIFIER). It checks if the current token matches any type in types:

  • If a match is found, the token is consumed via advance() and returned.
  • If none match, an UnexpectedToken exception is thrown with a descriptive error message listing all expected types and the actual one.
Parameters
typesList of acceptable token types (initializer list).
contextHuman-readable context for error reporting.
Returns
The matched token, already consumed from the stream.
Exceptions
UnexpectedTokenIf the current token does not match any expected type.
