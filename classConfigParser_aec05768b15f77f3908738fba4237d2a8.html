Server ConfigParser::parseServer ( )
private

Parses a single server block into a Server object.

Ensures the block starts with the server keyword and opening brace, then iterates through its directives and nested location blocks. Each directive is validated against duplicates (unless repeatable) and dispatched to the appropriate handler.

Returns
A fully populated Server object representing the parsed block.
Exceptions
SyntaxErrorIf the block is malformed, contains duplicate directives, or is missing the expected closing brace.
