Detailed Description

Represents an HTTP response to be sent back to the client.

Encapsulates all elements of an HTTP response:

  • Status line: numeric status code and reason phrase.
  • Headers: arbitrary key–value pairs such as Content-Type or Content-Length.
  • Body: inline string payload, file-backed content, or CGI-generated output.
  • Metadata: HTTP version, connection management, and offsets for CGI output.

Provides a clear API for constructing responses via setters, and utilities for serializing them (toHttpString) or checking response type (file-backed vs. CGI temporary file).

Typical workflow:

  • Built by method handlers (GET/POST/DELETE, CGI) or the ResponseBuilder.
  • Sent by the networking layer after request handling.
