Generates a simple HTML confirmation page for a deleted file.

Builds a minimal HTML5 document containing a title and message confirming that the requested file has been successfully deleted. The filename is HTML-escaped before insertion to prevent XSS.

A fully-formed HTML string suitable as the body of a 200 OK response.
