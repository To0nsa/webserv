Build the environment variables required for a CGI script execution.

Constructs a std::vector<std::string> of KEY=VALUE pairs following the CGI/1.1 specification. The environment includes:

  • Standard CGI variables (SCRIPT_NAME, PATH_INFO, REQUEST_METHOD, etc.).
  • Server metadata (SERVER_NAME, SERVER_PORT, SERVER_PROTOCOL, etc.).
  • Request headers, prefixed with HTTP_ and normalized (uppercased, - → _).
  • Content metadata (CONTENT_LENGTH, CONTENT_TYPE).

Special handling:

  • Computes PATH_INFO if the request URI extends beyond the script’s URI.
  • Sets REDIRECT_STATUS=200 for PHP compatibility.
Parameters
reqIncoming HTTP request.
serverServer configuration (name, port, defaults).
locMatched location block (provides root, CGI settings).
scriptPathAbsolute filesystem path of the CGI script to run.
Returns
A vector of strings representing the CGI environment, suitable for execve().
