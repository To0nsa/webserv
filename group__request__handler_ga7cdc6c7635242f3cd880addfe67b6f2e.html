bool &  ok 
)

Lists and sorts directory entries for autoindex generation.

Scans the given filesystem path and collects metadata into DirEntry objects. Handles errors in a non-throwing way using std::error_code. Results are separated into:

  • ".." (if parent exists, inserted at the front).
  • Subdirectories (sorted alphabetically).
  • Files (sorted alphabetically).

Each entry records:

  • name: filename or "..".
  • isDir: directory vs file.
  • size: file size in bytes (0 for directories).
  • mtime: last modification time (UTC).
Parameters
pathFilesystem path to the directory.
okReference flag set to false if the directory cannot be opened or scanned safely.
Returns
A vector of DirEntry objects sorted for autoindex rendering.
