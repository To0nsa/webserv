Detailed Description

Human-readable printing helpers for Webserv configuration and servers.

Implements utilities to format and print usage instructions and a structured, readable summary of the loaded configuration:

  • printUsage() prints CLI usage hints.
  • printServerHeader() prints a banner line for each server block.
  • printConfig() renders effective server/location settings (limits, methods, error pages, CGI, upload store, etc.).

These helpers are intended for diagnostics during startup and for developer/operator visibility of the parsed configuration.
