Handle a application/x-www-form-urlencoded POST request.

Parses the URL-encoded body of the request into key/value pairs, generates a simple HTML confirmation page, and writes it to a file at the given target path.

Workflow:

  • Parse form body using parseFormUrlEncoded.
  • Reject with 400 Bad Request if empty or malformed.
  • Build an HTML document containing submitted form fields.
  • Attempt to write the HTML to the specified file path.
    • On failure, return 500 Internal Server Error.
  • On success, return 201 Created with confirmation HTML.
Parameters
requestThe incoming HTTP request (provides form body).
serverThe server context (used for error generation).
fullpathFilesystem path where the HTML output should be saved.
filenameSuggested filename for confirmation message.
Returns
HttpResponse
  • 201 Created with confirmation HTML if saved successfully.
  • 400 Bad Request if form body is invalid.
  • 500 Internal Server Error if file operations fail.
