static std::string anonymous_namespace{handlePost.cpp}::generateFilename ( )
static

Generate a unique filename for uploaded files.

This function ensures that every uploaded file gets a unique name even under high concurrency. It combines:

  • Current time in nanoseconds since epoch (high resolution).
  • An atomic counter (uploadCounter) to break ties when multiple uploads happen within the same nanosecond.

The resulting filename follows the format:

upload_<nanoseconds_since_epoch>_<sequence_number>
Returns
std::string A unique, collision-resistant filename suitable for uploads.
