void ConfigParser::parseServerDirective ( Server &  server)
private

Parses and applies a single directive inside a server block.

Reads the current directive token (e.g., listen, host, etc.), collects its arguments, enforces a terminating semicolon, and then dispatches the directive to the appropriate handler function from the server handler table.

Parameters
serverReference to the Server object being populated.
Exceptions
SyntaxErrorIf the directive is malformed, missing arguments, or missing its terminating semicolon.
