Dispatches sending of the next queued response for a client.

Retrieves the front HttpResponse for the given client, logs its status via logResponseStatus, then delegates to the appropriate write path:

  • File-backed response → sendFileResponse (streams headers + file body).
  • In-memory response → sendRawResponse (single serialized buffer).

Both send paths are non-blocking; they may return early when the socket can’t accept more bytes. Any fatal error (including allocation failure) is caught here; the client connection is then closed to keep the server healthy.

Parameters
client_fdClient socket file descriptor.
indexIndex of the client FD in the poll list.
Note
This function assumes there is at least one queued response for client_fd. Callers should check the queue before enabling POLLOUT.
