HttpResponse anonymous_namespace{requestRouter.cpp}::dispatchByMethod ( const HttpRequest &  request,

Dispatches a validated request to the concrete method handler.

Assumes validateRequestMethod has already run, so only implemented-and-allowed methods reach this point. Dispatch is a simple chain on the request method:

  • "GET" → handleGet
  • "POST" → handlePost
  • "DELETE" → handleDelete
Parameters
requestParsed HTTP request.
serverActive server context.
locMatched Location.
Returns
The handler-produced HttpResponse.
Note
If additional methods are added in the future, extend this dispatcher (or switch to a table-driven approach).
