HttpResponse handlePost ( HttpRequest const &  request,
Server const &  server,
Location const &  location 
)

Handles an HTTP POST request end-to-end.

Pipeline: 1) Preconditions — validate body presence/size and that the Location has an upload_store (see validatePostRequest). Returns 400/413/403 on failure. 2) Target path preparation — resolve a safe destination under the location's upload store, forbid traversal/symlinks, create parent dirs, and choose a filename if needed (see preparePostTargetPath). Returns 404/403/500/400 on failure per checks. 3) Dispatch by Content-Type — select the concrete handler:

  • multipart/form-data → handleMultipartForm
  • application/x-www-form-urlencoded → handleUrlEncodedForm
  • otherwise → handleRawBody

On success, returns a 201 Created; on errors, returns the appropriate generated HttpResponse from earlier stages.

Parameters
requestIncoming HTTP request.
serverActive server context.
locationMatched location configuration (upload policy, paths).
Returns
A fully constructed HttpResponse.
