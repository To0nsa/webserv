bool SocketManager::parseAndQueueRequests ( int  client_fd)
private

Parses buffered client data into HTTP requests and queues them.

This function repeatedly attempts to parse complete HTTP requests from a client’s requestBuffer:

  1. Check request limits:
    • If headers exceed configured limits, clears buffer and pushes a 431 Request Header Fields Too Large error.
  2. Parse next request:
    • Uses HttpRequestParser::parse to decode from the buffer.
    • On success: consumes parsed bytes, resets state, and queues the request.
    • On incomplete parse (errorCode == 0): returns false to wait for more data.
    • On parse error (400, 411, 413, 415, etc.):
      • Marks the request with the error code.
      • Either clears the whole buffer (fatal errors) or erases consumed bytes.
      • Resets state and queues the error request.
  3. Loop continuation:
    • If more data remains in requestBuffer (and headers are present), parsing continues until buffer is exhausted or incomplete.
Parameters
client_fdFile descriptor of the client whose buffer is parsed.
Returns
true if parsing succeeded or error requests were queued, false if parsing is incomplete and more data is required.
