Detailed Description

Declares HTTP method handlers for GET, POST, and DELETE.

Declares handlers for supported HTTP request methods.

This header defines the public entrypoints for handling HTTP request methods within Webserv. Each function maps an incoming HttpRequest to an HttpResponse, using the active Server context and the matched Location configuration.

Supported methods:

  • GET: Serves static files or generates autoindex listings (see generateAutoindex).
  • POST: Handles uploads (raw body, URL-encoded, multipart forms).
  • DELETE: Removes existing files if permitted.

Helper:

  • generateAutoindex: builds a directory listing response in HTML.

This header exposes the top-level functions used by the request router to process method-specific logic:

  • handleGet: serve static files, run CGI, or generate autoindex listings.
  • handlePost: handle client uploads (raw body, URL-encoded forms, multipart forms).
  • handleDelete: remove existing resources from the server filesystem.

Additionally, it provides:

  • generateAutoindex: build a directory listing page when autoindexing is enabled.
  • handleMultipartForm: internal helper for parsing multipart form-data uploads.

These functions are invoked by the router after method validation (see requestRouter.cpp).
