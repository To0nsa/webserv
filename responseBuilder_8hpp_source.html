13/**
14 * @file responseBuilder.hpp
15 * @brief Declarations of helper functions for constructing HTTP responses.
16 *
17 * @details Defines the `ResponseBuilder` namespace, which provides a set of
18 * high-level factory functions for creating different types of
19 * @ref HttpResponse objects:
20 * - @ref generateSuccess : Builds a success response with an inline body.
21 * - @ref generateSuccessFile : Builds a success response backed by a file on disk.
22 * - @ref generateError : Builds an error response using a custom error page
23 * if available, or a default generated HTML fallback.
24 * - @ref generateRedirect : Builds a redirect response with a `Location` header.
25 *
26 * Also defines the `MessageHandler` namespace with
27 * @ref getDefaultMessage, a helper that maps HTTP status codes to
28 * their standard reason phrases.
29 *
30 * These functions are typically used by method handlers (GET/POST/DELETE/CGI)
31 * to generate complete responses ready for serialization and transmission
32 * by the networking layer.
33 *
34 * @ingroup http
35 */
