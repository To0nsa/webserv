Detailed Description

Encapsulates a client HTTP request.

Represents the full request received from a client connection, including the request line (method, target path, and protocol version), headers, body payload, and parsed URL components.

The class provides read/write accessors for all relevant fields, error codes for parse validation, and utility methods such as printRequest() for debugging. It is the central data structure produced by the HttpRequestParser and consumed by the router and method handlers during request processing.
