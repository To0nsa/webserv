Detailed Description

Implements directory autoindex (HTML listing) generation.

This file provides nginx-like autoindex functionality for HTTP GET requests on directories when no index file is found and autoindexing is enabled in the location block.

Main responsibilities:

  • Directory scanning (listDirectoryEntries): Collects entries, separates directories from files, preserves ...
  • Escaping utilities:
    • escapeUriComponent for safe URIs.
    • htmlEscape (from utils/htmlUtils) for HTML-safe output.
  • Formatting helpers:
    • formatMTimeUTC for human-readable UTC timestamps.
    • renderRow for HTML table rows with icons and metadata.
  • HTML layout:
    • htmlHeader and htmlFooter wrap the index table.
  • Entrypoint: generateAutoindex assembles the full HTML directory listing and returns a HttpResponse.

Errors (nonexistent or inaccessible directories) result in 403 responses. Valid directories produce a simple HTML table with:

  • File/directory name (with 📄/📁 icons).
  • Last modified timestamp (UTC).
  • File size (bytes).
