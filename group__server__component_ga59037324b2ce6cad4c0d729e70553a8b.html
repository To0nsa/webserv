void Server::addServerName ( std::string_view  name)

Adds a server name alias for this virtual host.

Server names are used to match the Host header of incoming HTTP requests. Multiple names can be added to support name-based virtual hosting. This method appends without deduplication.

Parameters
nameThe server name to add (e.g., "example.com").
