◆ isLikelyStartLine()

static bool isLikelyStartLine ( const std::string &  s)
static

Heuristically checks if a string looks like the start line of an HTTP request.

This helper is used to detect pipelined requests:

  • It tests whether the string begins with one of the known HTTP method tokens followed by a space (e.g., "GET ", "POST ").
  • Only a small subset of standard methods is recognized (GET, POST, DELETE, PUT, HEAD, OPTIONS, PATCH).

This is not a full request-line parser, but a lightweight heuristic to distinguish request boundaries in a raw buffer.

Parameters
sThe string segment to test (usually leftover buffer data).
Returns
true if s looks like a valid request start line, false otherwise.
