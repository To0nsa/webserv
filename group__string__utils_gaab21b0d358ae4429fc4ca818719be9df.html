Parses a non-negative integer from a string with context-aware error reporting.

Attempts to parse the entire value string into a non-negative integer using std::from_chars for efficient, allocation-free conversion. If parsing fails, the string contains extra characters, or the result is negative, a ConfigParseError is thrown. The error includes:

  • The field name for context.
  • The offending value.
  • The line and column numbers.
  • Additional context from context_provider, such as a snippet of the configuration file being parsed.
Parameters
valueString representation of the integer to parse.
fieldName of the configuration field being parsed.
lineLine number in the configuration source.
columnColumn number in the configuration source.
context_providerCallable returning a string snippet or context for diagnostics.
Returns
Parsed integer value (guaranteed to be non-negative).
Exceptions
ConfigParseErrorIf parsing fails, if extra characters remain after parsing, or if the parsed value is negative.
Note
This function is typically used when reading numeric configuration values (e.g., port numbers, limits) that must be whole, non-negative integers.
