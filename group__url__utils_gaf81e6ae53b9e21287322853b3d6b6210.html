std::string extractFilenameFromUri ( const std::string &  uri)

Extracts a safe filename from the last URI segment.

Takes the substring after the last / in uri, attempts percent-decoding, and validates the result against a conservative allowlist. Rejects empty, too-long (>256), or suspicious names (contains /, equals "." or "..", starts with . or -, or fails the regex ^[a-zA-Z0-9._-]+$).

Parameters
uriSource URI or path-like string.
Returns
A validated filename; returns an empty string if decoding fails or the candidate does not pass validation.
Note
Designed for deriving a download/upload filename from a URI segment without risking directory traversal or confusing special names.
