Handle a POST request with a raw body (no specific content type).

Writes the raw request body directly to the given filesystem path. Primarily used for generic uploads when the content type is not multipart/form-data or application/x-www-form-urlencoded.

Workflow:

  • Open target file for binary writing.
    • If opening fails, return 500 Internal Server Error.
  • Write the raw body from the request into the file.
    • If writing or closing fails, return 500 Internal Server Error.
  • On success, return 201 Created with confirmation HTML.
Parameters
requestThe incoming HTTP request (provides body to save).
serverThe server context (used for error generation).
fullpathFilesystem path where the body should be saved.
filenameName of the saved file (for confirmation message).
Returns
HttpResponse
  • 201 Created with confirmation HTML if saved successfully.
  • 500 Internal Server Error if file I/O fails.
