Logs the HTTP response status being sent to a client.

  • Formats a message indicating the status code and target file descriptor.
  • Logs at different severity levels depending on status code range:
    • < 400: Informational (success / redirection).
    • 400–499: Warning (client error).
    • >= 500: Error (server error).

This function is called before sending a response to provide visibility into the server’s behavior and help with debugging.

Parameters
statusThe HTTP status code of the response.
fdThe client file descriptor receiving the response.
