Detailed Description

Declares handler maps for server/location directives.

Provides the callable signatures and lookup tables used by ConfigParser to apply parsed directives to Server and Location instances. Each entry maps a directive keyword (e.g., "listen", "root") to a function that mutates the target object or throws on invalid arguments.
